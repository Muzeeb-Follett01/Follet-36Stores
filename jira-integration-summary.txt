===============================================================================
  JIRA ZEPHYR SQUAD INTEGRATION — SUMMARY
===============================================================================

PURPOSE:
  Automate uploading Playwright test results (screenshots & videos) to Jira
  Zephyr Squad test executions inside a test cycle.

FLOW:
  1. Script reads test-results/{storeId}/ folder (e.g. test-results/0026/)
  2. Each subfolder name (e.g. TMSHOP-455) maps to a Jira test case key
  3. Connects to Jira Server (jira.follett.com) using Personal Access Token
  4. Finds the target test cycle (default: "Test01") under "Unscheduled"
  5. Creates a test execution for each TMSHOP-XXX in the cycle
  6. Uploads all .png screenshots and .webm videos to each execution

===============================================================================
  FILES CREATED / MODIFIED
===============================================================================

  jira.env                    — Jira credentials config
                                (base URL, project key, username, PAT token)

  scripts/jiraAttach.ts       — Main script: connects to Zephyr Squad API,
                                creates executions, uploads attachments

  scripts/commands.txt        — Updated with the run command for reference

===============================================================================
  CONFIGURATION (jira.env)
===============================================================================

  JIRA_BASE_URL    = https://jira.follett.com
  JIRA_PROJECT_KEY = TMSHOP
  JIRA_USERNAME    = smuzeeb
  JIRA_API_TOKEN   = <Personal Access Token>

===============================================================================
  HOW TO RUN
===============================================================================

  # All test cases for a store:
  npx ts-node --transpile-only scripts/jiraAttach.ts 0026

  # Single test case only:
  npx ts-node --transpile-only scripts/jiraAttach.ts 0026 TMSHOP-455

  # Different cycle name:
  npx ts-node --transpile-only scripts/jiraAttach.ts 0026 ALL "MyCycle"

===============================================================================
  JIRA APIs USED
===============================================================================

  GET  /rest/api/2/project/{key}                  — Get project ID
  GET  /rest/zapi/latest/cycle?projectId=&ver...  — List test cycles
  POST /rest/zapi/latest/execution                — Create test execution
  POST /rest/zapi/latest/attachment?entityId=...   — Upload attachment to execution
  GET  /rest/zapi/latest/attachment/attachments... — Verify attachments (read)

  Authentication: Bearer token (Jira Personal Access Token)
