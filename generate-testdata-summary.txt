===============================================================================
  FULL END-TO-END AUTOMATION — SUMMARY
  From Store UI → Test Data Excel → Run Tests → Attach Results to Jira
===============================================================================

PURPOSE:
  Automate the entire flow: fetch course/textbook data from a Follett store's
  live UI, generate a ready-to-use test data Excel, run all 12 Playwright
  test specs, and attach screenshots/videos to Jira Zephyr Squad.

===============================================================================
  ONE COMMAND TO DO EVERYTHING
===============================================================================

  Replace XXXX with store number and adjust URL/password:

  npx ts-node --transpile-only scripts/courseDataFetch.ts https://bkstr-XXXX.myshopify.com/ bkstrXXXX; npx ts-node --transpile-only scripts/minCoverageFilter.ts; npx ts-node --transpile-only scripts/generateTestDataExcel.ts XXXX https://bkstr-XXXX.myshopify.com/ bkstrXXXX; $env:EXCEL_FILE='bkstr-XXXX.xlsx'; npx playwright test; npx ts-node --transpile-only scripts/jiraAttach.ts XXXX

  EXAMPLE (store 1097):

  npx ts-node --transpile-only scripts/courseDataFetch.ts https://bkstr-1097.myshopify.com/ bkstr1097; npx ts-node --transpile-only scripts/minCoverageFilter.ts; npx ts-node --transpile-only scripts/generateTestDataExcel.ts 1097 https://bkstr-1097.myshopify.com/ bkstr1097; $env:EXCEL_FILE='bkstr-1097.xlsx'; npx playwright test; npx ts-node --transpile-only scripts/jiraAttach.ts 1097

===============================================================================
  WHAT EACH STEP DOES
===============================================================================

  STEP 1: courseDataFetch.ts
    - Opens store URL in headless browser
    - Handles password gate if needed
    - Calls 3 Shopify/DDCS APIs to fetch campuses, terms, sections, textbooks
    - Output: output/courseData.json

  STEP 2: minCoverageFilter.ts
    - Reads courseData.json
    - Greedy set-cover: picks minimum courses covering all purchase types
      (buy-new, buy-used, rent-new, rent-used, digital)
    - Output: output/courseDataMinCoverage.json

  STEP 3: generateTestDataExcel.ts
    - Reads courseDataMinCoverage.json
    - Copies bkstr-0026.xlsx as template (112 columns, 13 test cases)
    - Opens store URL in browser to auto-fetch store logo text
    - Updates: store.url, store.password, storeLogoText on all rows
    - Fills courses + courseProducts JSON for 7 test cases
    - Output: testdata/Follett/bkstr-{storeId}.xlsx

  STEP 4: npx playwright test
    - Reads the generated Excel via EXCEL_FILE env variable
    - Runs all 12 specs (TMSHOP-450 through TMSHOP-463)
    - Each spec picks its row by specId from the Excel
    - Captures screenshots at key steps + records video
    - Output: test-results/{storeId}/TMSHOP-XXX/screenshots/ & videos/

  STEP 5: jiraAttach.ts
    - Reads test-results/{storeId}/ folder
    - Connects to Jira Zephyr Squad (jira.follett.com)
    - Creates test executions in Test01 cycle under Unscheduled
    - Uploads all screenshots (.png) and videos (.webm) per test case
    - Output: Attachments visible in Jira → TMSHOP → Test Cycles → Test01

===============================================================================
  THE PROBLEM (Before)
===============================================================================

  1. Run courseDataFetch.ts → produces output/courseData.json
  2. Run minCoverageFilter.ts → produces output/courseDataMinCoverage.json
  3. MANUALLY open courseDataMinCoverage.json
  4. MANUALLY copy course/textbook data
  5. MANUALLY paste into the correct rows/columns of the store Excel file
  6. MANUALLY update store.url, store.password, storeLogoText
  7. MANUALLY run tests
  8. MANUALLY upload screenshots/videos to Jira

  3. generateTestDataExcel.ts  → auto-generates Excel + fetches logo

===============================================================================
  SCRIPT ARGUMENTS
===============================================================================

  generateTestDataExcel.ts <storeId> [storeUrl] [storePassword]
    storeId       — 4-digit store number, e.g. 0001, 0026, 1097
    storeUrl      — optional, defaults to https://bkstr-{storeId}.myshopify.com/
    storePassword — optional, defaults to bkstr{storeId}
    storeLogoText — auto-fetched from live site (no manual input needed)

  jiraAttach.ts <storeId> [JIRA-TICKET] [cycleName]
    storeId       — 4-digit store number
    JIRA-TICKET   — optional, specific ticket or "ALL"
    cycleName     — optional, defaults to "Test01"
